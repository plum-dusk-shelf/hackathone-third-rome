Кастомная веб-IDE с встроенным терминалом, просмотром файлов, визуализацией графа Java-кода, анализом сложности и AI-оптимизацией через OpenRouter.

---

## Автоматическая установка


`mantbl.bat` — **автоматический** способ запуска IDE: скрипт сам проверяет окружение, ставит недостающие зависимости и открывает интерфейс для выбранного Java-проекта.
> ⚠️ **Важно.** Скрипт может не запуститься из-за неправильного перевода и того, как скачался, если не запускает попробуйте пересохранить и изменить перевод с помощью команд:
`$p = (Resolve-Path .\mantbl.bat).Path`, 
`$t = [IO.File]::ReadAllText($p)`,                  
`$t = $t -replace "`r?`n", "`r`n" `,                    
`[IO.File]::WriteAllText($p, $t, [Text.UTF8Encoding]::new($true))`
> После этого попробуйте снова запустить `mantbl.bat` или `.\mantbl.bat .`, если запускаете по пути, где лежит батник, в PowerShell или CMD.  
> ⚠️ **Важно.** Этот способ рассчитан на типовые сценарии. Если у вас нестандартное окружение (несколько версий JDK, изолированные venv/conda, корпоративные прокси) — **ручной подход, описанный далее в документе, может оказаться целесообразнее**. Автоматический запуск в таких случаях может вмешиваться в уже настроенное окружение.
> ⚠️ **Важно.** Настоятельно рекомендуем ввести свой OPENROUTER_API_KEY при исполнении mantb.bat, в противном случае режим оптимизации кода с помощью ИИ будет не доступен.
> ⚠️ **Важно.** Python и Java - скрипт не устанавливает их, а только проверяет наличие, указывает необходимую версию и даёт ссылки для ручной установки.

## Как запускать

Скрипт всегда принимает **путь к проекту** первым аргументом (в кавычках, если есть пробелы):

```bat
mantbl.bat "C:\dev\my-java-app"
```

## Ручная установка

### 1. Требования

- **Python 3.10+** (рекомендуется 3.11 или 3.12)
- **Windows 10/11** (для терминала нужен `pywinpty` и ConPTY — Windows 10 1809+)
- **JDK** (опционально — только если хотите компилировать Java-файлы вручную)
- **Аккаунт OpenRouter** (для AI-оптимизации): https://openrouter.ai

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

Для интерфейса используется официальный пакет **`webui2`**. Не устанавливайте одноимённый `webui` с PyPI: это другой проект, зависящий от PySide. Если он уже установлен, удалите его перед установкой:

```bash
pip uninstall webui
```

Если `requirements.txt` нет — установите вручную:

```bash
pip install webui2 fastapi uvicorn[standard] websockets javalang pywinpty requests python-dotenv
```

### 3. Настройка API-ключа OpenRouter(можно пропустить если в проекте уже есть .env файл)

AI-функции (оптимизация графа) требуют ключ OpenRouter. Получите его на https://openrouter.ai/keys.

**Способ A — через `.env` (рекомендуется):**

Создайте файл `.env` в папке проекта:

```env
OPENROUTER_API_KEY=sk-or-v1-ваш_ключ_здесь
```

Затем в `graph_optimizer_llm.py` добавьте в начало:

```python
from dotenv import load_dotenv
load_dotenv()
```

**Способ B — через переменную окружения:**

```cmd
:: Windows CMD
set OPENROUTER_API_KEY=sk-or-v1-ваш_ключ_здесь

:: Windows PowerShell
$env:OPENROUTER_API_KEY="sk-or-v1-ваш_ключ_здесь"

:: Linux / macOS
export OPENROUTER_API_KEY="sk-or-v1-ваш_ключ_здесь"
```

> Без ключа IDE запустится, но кнопка «Оптимизировать» будет возвращать ошибку `401 Missing Authentication header`.

### 4. Запуск

```bash
python test_main.py
```

Откроется окно IDE (WebUI). Запуск не зависит от текущей папки PowerShell/CMD: файлы проекта и интерфейс открываются относительно расположения `test_main.py` (или собранного `.exe`). Терминал и Java-отладчик используют локальный сервер на `127.0.0.1:8086`. Если сервер уже запущен этим проектом, новый экземпляр IDE использует его; если порт занят другим приложением, IDE сообщит об этом и попросит освободить порт.

## Функционал

### 🗂️ Панели (перетаскиваются из левого сайдбара)

Каждая панель — отдельный tab. Их можно:

- **Перетаскивать** в рабочую область
- **Менять местами** (drag-and-drop заголовка)
- **Масштабировать** (тянуть за правый/нижний край)
- **Сворачивать** в верхнюю панель (как вкладки браузера)
- **Закрывать** с проверкой несохранённых изменений

### 📁 Explorer

- Дерево файлов проекта с раскрывающимися папками
- Клик по файлу — открывает его в редакторе
- Автоматически игнорирует `.git`, `__pycache__`, `venv`, `.venv`, `.jdtls-data`, `node_modules`, `build`, `dist`

### 📝 Редактор

- Подсветка номера строк (gutter)
- Настройки IDE доступны по кнопке ⚙ внизу левой панели: можно изменить цвета подсветки Java, идентификатор модели OpenRouter и сочетания клавиш запуска/отладки
- Настройки сохраняются в `settings.json` рядом с приложением; выбранная модель используется при следующем запросе оптимизации графа
- Панель «Сложность (Big O)» анализирует выбранную вершину-метод в графе через ИИ: показывает текущую временную сложность, формулу, ожидаемое ускорение и краткое описание узкого места
- **Точки останова** (breakpoints): двойной клик по номеру строки
- Индикатор **несохранённых изменений** (белая точка в заголовке)
- **`Ctrl+S`** — сохранить файл
- Если открыто несколько редакторов с изменениями — появляется модальное окно выбора

### ⌨️ Терминал

- Настоящий **ConPTY**-терминал (`pywinpty`) — работает cmd и PowerShell
- **`Backspace`**, стрелки, `Ctrl+C` — всё как в реальном терминале
- Цвета ANSI, `\r`-прогресс-бары
- Работает через WebSocket, не блокирует UI
- Каждый терминал — отдельный процесс

### 🕸️ Граф

- Парсинг Java-кода через `javalang` → AST → граф классов, методов и вызовов
- Граф автоматически строится по коду редактора при открытии Java-файла или панели графа; кнопка **Из кода** пересчитывает его после изменений
- **Оптимизировать** — отправить код в LLM (Nemotron 3 Ultra), получить граф с оптимизированными методами, применить изменения к исходному файлу и перерисовать граф
- Используется `vis-network` для интерактивной визуализации

### 📊 Сложность (Big O)

- Эвристический анализ временной сложности: `O(1)`, `O(n)`, `O(n²)`, `O(n³)`, `O(log n)`
- Учитывает вложенность `for`/`while`, рекурсию, деление пополам
- Кнопка **Обновить** для пересчёта

### 💻 Консоль

- Логи в реальном времени: `read_file`, `parse_java`, `optimize_graph`, `[LLM] ...`
- Временные метки, автоскролл
- Позволяет видеть, что происходит внутри Python-процесса, не переключаясь в терминал

### ▶️ Запуск / 🐞 Дебаг

Кнопки в верхней панели запускают и отлаживают выбранный Java-файл через Java debug-сервер в `server/`. Перед запуском содержимое редактора сохраняется; точки останова для отладки задаются двойным щелчком по номеру строки. Вывод и статусы запуска появляются в панели «Консоль» и в существующей панели «Терминал»; вывод программы отображается построчно с меткой времени. Ввод для интерактивных Java-программ набирается в панели «Терминал» и отправляется клавишей Enter; после завершения программы терминал снова передаёт ввод PowerShell. Если выполнение остановлено на breakpoint перед `Scanner.nextLine()`, введённая строка будет передана Java, но программа обработает её только после нажатия «Продолжить». Кнопки шагов доступны только пока программа приостановлена; «Пауза» доступна во время выполнения. При остановке на breakpoint редактор подсвечивает текущую строку; кнопка «Переменные» открывает отдельное окно со значениями переменных, доступных в выбранном кадре стека. Кадры можно выбирать, а объекты и массивы — раскрывать для просмотра полей и элементов. Java debug-сервер доступен через встроенный FastAPI-сервер по адресу `127.0.0.1:8086/debug`.

и прочие полезные возможности...

Для запуска и отладки требуется JDK, JDT Language Server и плагин `java-debug`; инструменты можно подготовить командой `python setup_tools.py`. Файл должен находиться внутри рабочей папки `WORKSPACE` (по умолчанию корень проекта).

## Структура проекта(основа)

```
ide/
├── test_main.py              # главный скрипт, биндит Python-функции к JS
├── index.html                # весь фронтенд (HTML + CSS + JS)
├── fastapi_server.py         # WebSocket-сервер для терминалов
├── parser.py                 # javalang → граф (nodes/edges)
├── graph_optimizer_llm.py    # LLM → оптимизированный граф → новый код
├── requirements.txt
├── ide.spec                  # конфиг для pyinstaller (сборка в .exe)
├── BigMess.java              # тестовый Java-файл (для проверки оптимизации)
├── TestGraph.java            # тестовый Java-файл (для графа)
└── .env                      # OPENROUTER_API_KEY (не коммитить!)
```

## Сборка в `.exe` (опционально)

```bash
pyinstaller ide.spec --clean
```

Результат — папка `dist/MyIDE/` с `MyIDE.exe` и всеми зависимостями.

**Что важно:**

- В `ide.spec` в `datas` указан абсолютный путь к `webui-2.dll` — замените на свой:
  ```
  (r'C:\Users\ВАШ_ПУТЬ\anaconda3\Lib\site-packages\webui\webui-windows-msvc-x64\webui-2.dll', '.')
  ```
- Исключены тяжёлые библиотеки (`torch`, `tensorflow`, `pandas`, и т.д.), чтобы `.exe` был компактным
- При запуске `.exe` API-ключ OpenRouter берётся из `.env` (если положить его рядом с `.exe`) или из переменной окружения системы

## Известные ограничения

- **Терминал работает только на Windows** (из-за `pywinpty` и ConPTY). На Linux/macOS нужен `pty`-фолбэк.
- **Одна модель** для AI-оптимизации — `nvidia/nemotron-3-ultra-550b-a55b:free`. Лимиты OpenRouter: **20 запросов/мин, 50/день** на бесплатном аккаунте.
- **Парсер Java** использует AST `javalang` и строит классы, методы и определяемые по локальным типам вызовы. Вызовы внешних типов не отображаются, а перегруженные одноимённые методы объединяются в узел `Класс.метод()`.
- **Big O** — эвристика по вложенности циклов, а не настоящий математический анализ.
- **Нет автосохранения** — изменения в редакторе сохраняются только по `Ctrl+S` (или автоматически после оптимизации).

## Пользовательская инструкция для работы с IDE(Горячие чклавиши)



## Редактор кода

| Комбинация / действие | Что делает |
|---|---|
| **Ctrl+S** (или **Cmd+S** на macOS) | Сохранить текущий файл. Если в нескольких редакторах есть несохранённые изменения — открывает модальное окно: «Сохранить текущий» / «Сохранить все» / «Отмена». |
| **Двойной клик по полю слева от номера строки** (gutter) | Поставить/снять точку останова (breakpoint) на этой строке. Отображается красной точкой. |
| **Клик в редактор** | Сделать редактор активным (`selectedEditor`). Если редактор входит в фокусную группу, файл из Explorer откроется именно в нём. |
| **Shift+клик по панели** | Добавить/убрать панель из фокусной группы (редакторы, графы, терминалы и т.п.). |
| **Обычный клик по панели** | Сбросить группу и оставить в фокусе только эту панель. |
| **Клик по Explorer** | Если группа не пуста — Explorer добавляется к ней (другие Explorer-панели сбрасываются); если группа пуста — становится единственной выделенной. |
| **ПКМ (правая кнопка мыши)** | Сбросить фокусную группу (все панели возвращаются к нормальному виду). |

## Explorer

| Действие | Что делает |
|---|---|
| **Клик по папке** | Развернуть/свернуть дерево. |
| **Клик по файлу** | Открыть файл во всех **выделенных** редакторах/графах. Если группа не выделена — во всех доступных контент-панелях. |
| **Клик по файлу при выделенном редакторе** | Открыть файл только в этом редакторе (и в выделенных графах). |

## Панели (заголовок)

| Действие | Что делает |
|---|---|
| **Клик по заголовку панели** | Сделать панель активной (подсветка `active-panel`). |
| **Перетаскивание заголовка** (drag) | Поменять панели местами (с сохранением размеров). Работает и между рядами. |
| **Кнопка `−` в заголовке** | Свернуть панель в верхнюю панель вкладок. |
| **Кнопка `×` в заголовке** | Закрыть панель. Для редактора с несохранёнными изменениями — подтверждение. |
| **Двойной клик по ресайзеру** (правый край панели) | Сбросить ширину панели к `flex:1`. |
| **Двойной клик по ресайзеру** (нижний край панели) | Сбросить высоту панели и её ряда к `flex:1`. |

## Drag & Drop

| Действие | Что делает |
|---|---|
| **Перетаскивание заголовка панели на другую панель** | Поменять панели местами (сохраняя размеры). Работает и между рядами: если панель из ряда A бросить на панель из ряда B, они поменяются местами вместе со своими стилями (`flex`, `width`, `height`). После обмена — `window.dispatchEvent(new Event('resize'))`, чтобы vis-network/xterm подогнали размер. |
| **Перетаскивание заголовка панели на пустое место рабочей области** | Не обрабатывается (drop разрешён только на другую панель — `.panel.dragover`). |
| **Перетаскивание элемента из Sidebar** (Explorer / Редактор / Терминал / Граф / Сложность / Консоль) на рабочую область | Создать новую панель этого типа. Область подсвечивается (`#workspace.drag-over`). |
| **Перетаскивание свёрнутой вкладки** (`.collapsed-tab`) на рабочую область | Развернуть панель из вкладки. |
| **Перетаскивание свёрнутой вкладки внутри панели вкладок** | Изменить порядок (визуально). |

## Тулбар (верхняя панель)

| Действие | Что делает |
|---|---|
| **Кнопка «Запуск»** | Запустить Java-программу из выбранного `.java`-файла. Используется тот же приоритет выбора редактора, что и в дебаге: `.java` из фокусной группы → активный редактор → первый `.java`-редактор на поле. |

## Терминал

| Действие | Что делает |
|---|---|
| **Ввод в терминал** | Передаётся по WebSocket в `/ws/{term-id}`. Если в этот момент активен Java-процесс — идёт в stdin Java (через `cmd: 'input'`). |
| **Enter** | Отправить введённую строку (в Java — `\n`, в shell — как обычно). |
| **Ctrl+C** | Прервать Java-процесс (`cmd: 'stop'`). |
| **Backspace** | Удалить последний введённый символ в буфере Java. |
| **Ресайз окна/панели** | Автоматически подстраивает размер через `fit.fit()`. |

## Модальные окна

| Действие | Что делает |
|---|---|
| **Кнопка «Отмена»** | Закрыть модалку без действия. |
| **Кнопка «ОК»** | Подтвердить / принять уведомление. |
| **Кнопка «Сохранить текущий»** | Сохранить только текущий редактор, затем выполнить отложенное действие. |
| **Кнопка «Сохранить все»** | Сохранить все «грязные» редакторы, затем выполнить отложенное действие. |
| **Клик вне окна** | Не закрывает модалку (нужно нажать кнопку). |

## Диагностика и лог

| Действие | Что делает |
|---|---|
| **F12 (в окне WebUI)** | Открыть DevTools (полезно, если что-то не работает: `[IDE][openFile]`, `[Java]` и т.п. в консоли). |
| **Панель «Консоль»** | Показывает логи `appendLog`. Если консоли нет — логи дублируются в `console.log` браузера. |
